📋 项目背景

新疆作为多民族聚居地区，拥有丰富的非物质文化遗产资源。然而，传统非遗传播方式以静态展示为主，缺乏互动性和沉浸感，年轻人对非遗的了解途径有限。

本项目利用AIGC技术，将新疆非遗文化以多模态、可交互的形式呈现，让用户通过浏览、创作、互动、答题等多种方式，沉浸式体验新疆各民族非遗文化之美。

🛠️ 技术方案

Python + Flask HTML / CSS / JavaScript AIGC 内容生成 AI 语音合成 HTML5 Audio

项目采用轻量级Web架构，后端使用 Python Flask 框架提供页面路由与内容服务，前端使用原生 HTML/CSS/JavaScript 开发，不依赖任何前端框架与外部 CDN，断网环境下仍可完整演示。

图文讲解、纹样素材与语音讲解均已本地化部署，AIGC 接口作为可选增强能力接入：未配置密钥时运行演示数据版本，配置后自动切换为实时生成。

✨ 创新点

  • 多模态融合：文字、图片、语音、音乐多模态结合，全方位呈现非遗文化
  • 生成式创作：用户输入关键词，生成新疆民族风格纹样，从“观看”到“参与创作”
  • 互动式学习：乐器弹奏、知识问答等游戏化设计，提升学习趣味性
  • 地域文化数字化：立足新疆本土非遗，用科技手段助力民族文化传播

📁 功能模块

  • 非遗浏览：5 个代表性非遗项目的图文与语音讲解，并梳理纹样演变脉络
  • 纹样生成器：输入关键词生成新疆民族风格纹样
  • 冬不拉弹奏：互动式乐器体验，支持手动拨弦和预设旋律播放
  • 知识问答：非遗知识小测验，游戏化学习
  • 服饰展示：新疆各民族传统服饰图文展示，附常见服饰元素图鉴
  • 非遗地图：依据公开行政区划数据绘制的分布地图，点击城市标记查看对应项目
  • 纹样祈福：以抽签形式认识民族纹样母题，了解其寓意
  • AI 换装：上传照片，由图像编辑模型换上各民族传统服饰

⚠️ AIGC内容标注

本作品中部分图片、语音、文字内容由AI辅助生成，已在页脚统一标注。

非遗知识内容参考公开资料整理，并尽量核对权威来源；如有疏漏或表述不当之处，欢迎指正，我们将及时修订。

本作品仅供教学展示与文化传播使用，不用作任何商业用途。
