# 基于AIGC的新疆非遗文化互动体验平台

第十四届全国大学生数字媒体科技作品竞赛参赛作品 —— 一个基于 Python Flask 的 Web 应用，收录新疆 5 个国家级非物质文化遗产项目。

## 项目简介

平台以「看、听、弹、画、穿、答」多种方式呈现新疆非遗：既能看图文与语音讲解，也能亲手画纹样、弹冬不拉、上传照片体验民族服饰，把原本静态的文化展示变成可以参与的互动体验。

技术上采用「预置数据 + 真实 AI 接口」双轨设计：**未配置 API Key 或断网时自动降级为演示模式**，保证任何环境下都能完整演示。

## 功能模块

| 模块 | 说明 |
|------|------|
| 非遗浏览 | 5 个项目的图文、语音讲解与纹样演变时间线 |
| 纹样生成器 | 关键词生成 / 手绘创作：画几笔，AI 沿笔触补全成完整民族纹样 |
| 冬不拉弹奏 | 点击琴钮发声 + 预设旋律，附形制、演奏与阿肯弹唱知识 |
| 知识问答 | 10 道非遗知识选择题，即时判分与逐题解析 |
| 服饰展示 | 各民族传统服饰图文 + 服饰元素图鉴 |
| 非遗地图 | 依据公开行政区划数据绘制的分布地图，支持地州悬停与列表联动 |
| 祈福抽签 | 抽取民族纹样母题，了解其寓意 |
| AI 换装 | 上传照片，由图像编辑模型生成民族服饰形象 |
| 关于项目 | 项目背景、技术方案、AIGC 标注与团队分工 |

## 技术栈

- **后端**：Python + Flask
- **前端**：原生 HTML / CSS / JavaScript（不引用任何外部 CDN，断网可运行）
- **AI 能力**
  - 硅基流动 `Qwen/Qwen-Image-Edit-2509`（图生图）—— AI 民族换装、手绘纹样补全
  - DeepSeek `deepseek-flash`（文本）—— 纹样文字解读
- **图像处理**：Pillow —— 手绘纹样的本地合成，作为接口不可用时的降级路径

## 运行方式

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2.（可选）配置 API Key —— 不配置也能运行，相关功能会自动降级
#    在项目根目录新建 config_local.py：
#      SILICONFLOW_API_KEY = "sk-..."
#      DEEPSEEK_API_KEY   = "sk-..."

# 3. 启动
python app.py
```

启动后访问 <http://127.0.0.1:5000>。Windows 下也可直接双击 `start.bat`。

## 关于素材文件

仓库**不包含图片与音频素材**（体积过大），因此克隆后运行会看到图片无法显示。

素材位于 `static/images/`（非遗图片、纹样素材、服饰图）与 `static/audio/`（语音讲解、乐器音符），需自行准备。

## AIGC 内容标注

本作品中部分图片、文字、音频内容由 AI 辅助生成，各页面页脚均已统一标注。

非遗名录年份依据**中国非物质文化遗产网**（ihchina.cn）项目页核对。

## 说明

- `config_local.py` 已写入 `.gitignore`，不会被提交；**请勿把 API Key 写进代码或提交记录**。
- `build_map.py` 用于生成非遗地图的边界数据（数据源：阿里云 DataV.GeoAtlas 公开行政区划数据）。
- 所有页面模板继承 `templates/base.html`，导航与配色统一由 `static/css/style.css` 提供；新增页面请遵循此约定。
